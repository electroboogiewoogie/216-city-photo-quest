# 216 · Городской фотоквест

`city-photo-quest` — браузерное приложение без сервера. Автор собирает квест из фотографий деталей города: вопрос, подсказка и варианты ответа к каждому заданию. Игрок проходит задания по порядку, неверный ответ не открывает следующее. Готовый квест скачивается одним HTML-файлом с фотографиями и проигрывателем внутри: его можно переслать и открыть в браузере телефона без интернета. Черновик хранится в IndexedDB браузера, прогресс игрока — в localStorage по идентификатору квеста.

## Быстрый старт: готовая сборка

Готовая статическая сборка лежит в папке `dist/` (входит в ZIP-выпуск, в git не коммитится). Открывайте её через локальный HTTP-сервер.

```bash
node scripts/serve-static.mjs --dir dist --port 4316 --base /   # Node.js 22.12+
# или: python3 -m http.server 4316 --directory dist
# открыть http://127.0.0.1:4316/
```

Сборка использует относительные пути и работает и из корня сайта, и из вложенного пути вроде `https://<user>.github.io/city-photo-quest/`.

## Демонстрационный сценарий

1. **«Открыть демо-квест из трёх заданий»**: «Детали Старого квартала» — табличка с годом над аркой, флюгер, табличка с названием улицы. «Фотографии» нарисованы для проекта в SVG.
2. В третьем задании впишите в «Проверить, примется ли ответ» `  ул.  елочная ` — «Примется: совпал с «ул. Ёлочная»». Регистр, лишние пробелы, кавычки и «ё/е» не важны.
3. **«Пройти квест»**: ответ `1908` — «Неверно. Попыток на этом задании: 1», задание не меняется. `1907 ГОД` — следующее задание. «Показать подсказку» во втором задании, затем `петушок`, `Ёлочная` — «Квест «Детали Старого квартала» пройден!», попыток и подсказок по итогу.
4. **«Скачать квест для игры (.html)»** скачает `kvest-detali-starogo-kvartala.html`. Откройте файл в другом браузере или на телефоне, интернет можно выключить: всё нужное внутри файла.
5. **«Сохранить пакет для редактирования (.json)»** — перенос черновика на другой компьютер, «Открыть пакет…» — обратно.

## Разработка, проверки и сборка

Требования: Node.js 22.12 или новее, npm 10+.

```bash
npm ci                      # зависимости строго по package-lock.json
npm run dev                 # http://localhost:5216/
npm run typecheck
npm test                    # Vitest: проверка ответов, редактор, прогресс, выгрузка
npm run build               # сборка в dist/
npm run e2e:install         # один раз: Chromium для Playwright
npm run e2e                 # Playwright по dist/: вложенный путь /city-photo-quest/ и корень (порты 4316, 4416)
npm run verify              # всё подряд
```

## Где что лежит

| Путь | Назначение |
|---|---|
| `src/core/quest-editor.ts` | формат пакета, правки заданий, проверка готовности, разбор файла пакета |
| `src/core/answer-checker.ts` | нормализация и сравнение ответа с вариантами |
| `src/core/player-progress.ts` | прогресс игрока: открытое задание, попытки, подсказки, хранение по id пакета |
| `src/core/quest-export.ts` | сборка самостоятельного HTML с данными, картинками и проигрывателем |
| `src/core/image.ts`, `store.ts`, `demo.ts` | уменьшение фото, черновик в IndexedDB, демо-квест |
| `src/App.tsx`, `src/ui/` | редактор, игра в приложении, автосохранение черновика |
| `e2e/` | Playwright |
| `docs/` | карточка, архитектура, приёмка, ассеты, исходное ТЗ |

## Данные

Черновик — IndexedDB `city-photo-quest` в этом браузере, прогресс — localStorage `cpq.progress.<id квеста>`. Фото при загрузке уменьшаются до 1280 px по длинной стороне и перекодируются в JPEG: так квест из 10 заданий весит 1–3 МБ. Чтобы перенести черновик или сделать копию, сохраните пакет `.json`.
