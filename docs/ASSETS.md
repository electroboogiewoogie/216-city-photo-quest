# Ассеты и сторонние материалы

Сторонних изображений, фотографий, шрифтов, звуков и других материалов в проекте нет.

| Файл | Происхождение | Права |
|---|---|---|
| `public/favicon.svg` | нарисован вручную для проекта (фотоаппарат, SVG-примитивы) | собственный материал проекта |
| Демо-квест «Детали Старого квартала»: три «фотографии» (фасад с табличкой «1907», флюгер-петух, табличка «ул. Ёлочная, 12») | нарисованы вручную для проекта в SVG, `src/core/demo.ts`. Квартал и улица вымышлены | собственный материал проекта |
| Картинки в e2e-тестах | SVG-прямоугольники с подписью и шумовые JPEG, генерируются тестами | синтетические данные |
| Шрифты | системные (`system-ui`), не загружаются; в выгруженном квесте — тоже системные | — |

Фотографии, которые автор квеста загружает сам, остаются в его браузере и в его файлах. Приложение никуда их не отправляет.

Зависимости npm (React, Vite, TypeScript, Vitest, Playwright и их транзитивные пакеты) не копируются в репозиторий, их точные версии зафиксированы в `package-lock.json`.

## Лицензии кода в сборке

В `dist/` попадает код production-зависимостей: `react`, `react-dom`, `scheduler` (все MIT). Сборщик удаляет лицензионные комментарии, поэтому тексты лицензий лежат отдельно: `public/THIRD_PARTY_LICENSES.txt` → `dist/THIRD_PARTY_LICENSES.txt`. Файл пересобирается из `node_modules` перед каждой сборкой (`scripts/third-party-licenses.mjs`). Dev-зависимости в сборку и ZIP не входят.

Выгруженный HTML-квест не содержит кода React: в него встраивается только собственный проигрыватель проекта (`standalonePlayer`, `normalizeAnswer`) и данные квеста.
