# Карточка продукта

| Поле | Значение |
|---|---|
| Номер | 216 |
| Название | Городской фотоквест |
| Репозиторий | `city-photo-quest` |
| Профиль | браузерное приложение без сервера: React + TypeScript + Vite, GitHub Pages |
| Версия | 1.0.0 (четвёртая партия, 2026-11-21) |

## Аудитория и задача

Учитель краеведения, экскурсовод, организатор тимбилдинга или родитель, который хочет устроить прогулку-игру по району. Нужно быстро собрать задания «найди деталь на фото и ответь на вопрос» и раздать их игрокам так, чтобы на улице всё работало с телефона, без установки приложений и без мобильного интернета.

## Сценарий

1. Автор фотографирует детали: табличку, флюгер, лепнину, вывеску.
2. В редакторе на каждое задание — фото, вопрос, подсказка и варианты ответа. Проверка «примется ли ответ» показывает, что будет принято.
3. «Скачать квест для игры» даёт один HTML-файл. Автор пересылает его игрокам.
4. Игрок открывает файл в браузере телефона, проходит задания по порядку, при необходимости берёт подсказку. Прогресс сохраняется, если закрыть вкладку.

## Функции версии 1.0

- Редактор: название, вступление, до 40 заданий, порядок «выше/ниже», удаление с подтверждением, загрузка фото с уменьшением до 1280 px, описание фото для экранного диктора.
- Варианты ответа по строкам, сравнение без учёта регистра, лишних пробелов, кавычек и «ё/е».
- Проверка готовности: без вопроса или вариантов ответа квест не выгружается, без фото — предупреждение.
- Игра в приложении и в выгруженном файле с одинаковыми правилами: попытки, подсказка, прогресс по id квеста, итог.
- Самостоятельный HTML без сетевых запросов. Пакет JSON для переноса черновика.
- Черновик в IndexedDB с защитой от потери текста при закрытии вкладки.

## Практический результат

Демо-квест из трёх заданий выгружается в файл 11 КБ. Квест из 40 заданий с фото 1280×960 (худший случай — шумные кадры, 32 МБ) открывается в редакторе за 3 с, выгружается за 0,7 с, выгруженный файл стартует за 0,8 с.

## Границы текущей версии

- Нет GPS, карты и распознавания фото: проверяется только текст ответа.
- Нет таблицы результатов игроков: прогресс хранится у каждого игрока в его браузере.
- Опечатки и другой порядок слов не прощаются: все допустимые варианты автор перечисляет сам.
- Прогресс выгруженного файла хранится в localStorage браузера. В некоторых браузерах файлы, открытые с диска (`file://`), не сохраняют localStorage между запусками — тогда прогресс живёт до закрытия вкладки.
