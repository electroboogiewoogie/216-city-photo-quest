# Правила работы с проектом 216 Городской фотоквест

Браузерное приложение React + TypeScript + Vite без сервера. Черновик квеста — IndexedDB, прогресс игрока — localStorage, перенос — пакет JSON, игра на телефоне — самостоятельный HTML-файл.

## Где что находится

- Интерфейс и публичные маршруты — `index.html`, `src/main.tsx`, `src/App.tsx` (`#edit` — редактор, `#play` — игра), `src/ui/Editor.tsx`, `src/ui/Player.tsx`, `src/ui/useQuestDraft.ts`, `src/styles.css`.
- Предметная логика и хранение — `src/core/quest-editor.ts`, `src/core/answer-checker.ts`, `src/core/player-progress.ts`, `src/core/quest-export.ts`, `src/core/image.ts`, `src/core/store.ts`.
- Данные, ассеты и демоматериалы — демо `demoQuest()` в `src/core/demo.ts` (SVG-рисунки, нарисованы для проекта), иконка `public/favicon.svg`, готовая сборка `dist/`.
- Тесты и документация — `src/core/core.test.ts` (Vitest), `e2e/*.spec.ts` (Playwright), `docs/`.

## Команды и сценарий

- Установка — `npm ci`, для e2e один раз `npm run e2e:install`.
- Запуск и адрес — `npm run dev` → http://localhost:5216/; готовая сборка `npm run serve:dist` → http://127.0.0.1:4316/.
- Проверки и сборка — `npm run typecheck`, `npm test`, `npm run build`, `npm run e2e` (порты 4316 и 4416), всё вместе `npm run verify`.
- Данные и результат показательного сценария — «Открыть демо-квест из трёх заданий» → «Пройти квест»: `1908` неверно, задание не меняется → `1907 ГОД` принят → подсказка и `петушок` → `Ёлочная` → «пройден». «Скачать квест для игры (.html)» → `kvest-detali-starogo-kvartala.html` работает в другом профиле без сети.

## Инварианты проекта

- `normalizeAnswer` — одна нормализация для ввода и вариантов: NFC, нижний регистр, ё→е, без кавычек, неразрывные и двойные пробелы → один пробел, знаки препинания по краям убраны. Порядок слов и опечатки не исправляются.
- `normalizeAnswer` и `standalonePlayer` встраиваются в выгрузку через `toString()`: они самодостаточны (без импортов и обращений к другим функциям модуля). Тест `core.test.ts` компилирует их текст отдельно — не ломайте это.
- Правила игры одинаковы в приложении (`player-progress.ts`) и в выгрузке (`standalonePlayer`): неверный ответ не открывает следующее задание, пустой не считается попыткой, ключ прогресса `cpq.progress.<id пакета>`.
- Выгруженный HTML: CSP `default-src 'none'; img-src data:` — никаких сетевых запросов. JSON данных экранирует `<`, U+2028 и U+2029, тексты вставляются через `textContent`.
- Черновик: следующее состояние считается от `latest.current` до `setState` (иначе сохраняется старая версия). Действия сохраняются сразу, набор текста — через 300 мс, на `pagehide` несохранённый текст пишется в localStorage и накладывается при следующем открытии.
- Пакет из файла проходит `parsePackage` (формат, версия, задания, только `data:image/…`, размер) до замены черновика. Имена файлов — транслитом.
- Сборка с `base: './'`: e2e-проекты `nested-path` и `root-path`.
